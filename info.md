# Мини-сайт свадебного приглашения — ТЗ для разработки

## Контекст
Свадебный сайт-приглашение — общая ссылка, которую жених и невеста разошлют гостям
(WhatsApp/Telegram). Без персонализации под конкретного гостя, без формы RSVP —
просто красивое цифровое приглашение с ключевой информацией.

Контакты для связи:

  — отец невесты, Алишер: +992 91 867 33 83

## Языки
Двуязычный контент: русский и таджикский.
Реализовать переключатель языка (простой toggle RU / TJ в углу экрана,
без библиотек i18n — достаточно объекта с двумя наборами строк и computed-реактивности).
Дефолтный язык — русский.

## Технологии
- Vue 3 (Composition API, <script setup>)
- Tailwind CSS
- GSAP (+ ScrollTrigger при необходимости) для анимаций
- Никаких тяжёлых UI-фреймворков — всё пишется вручную под этот конкретный дизайн
- Один self-contained билд, оптимизированный под мобильные устройства
  (большинство гостей откроют ссылку с телефона на медленном мобильном интернете
  в Таджикистане — это критично для тех. решений ниже)

## Дизайн-язык
Романтичный, воздушный, «мягкий люкс» — вдохновение Nothing OS 5.0
(чистая геометрия, дот-матрица, моноширинные акценты, много воздуха),
но переосмысленный в тёплой свадебной палитре:
- Основа: тёплый молочно-бежевый / кремовый фон (не белый и не серый Nothing)
- Акцент: приглушённое золото (#C9A15E — или близкий тон) вместо красного
- Второй акцент (опционально): глубокий бордовый или терракотовый для контраста
- Типографика: контраст засечного романтичного шрифта для имён
  (например, что-то вроде Playfair Display / Cormorant) и лёгкого гротеска
  для служебного текста (сама Nothing-эстетика через moноширинный/tracking-wide текст
  для лейблов: ДАТА, МЕСТО, КОНТАКТЫ)
- Много белого пространства, тонкие линии-разделители, минимум декоративного шума
- Едва заметная текстура бумаги/льна на фоне — опционально, если не бьёт по весу страницы

## Структура — строго 2 экрана

### Экран 1 — Hero / объявление
- Полноэкранный, первое, что видит гость
- Анимация лепестков (GSAP): плавно, медленно падают/парят на фоне,
  не хаотично — сдержанно и элегантно, не должны отвлекать от текста
- По центру — имена «Хисрав & Фариштабону» крупным романтичным шрифтом,
  между именами — тонкий орнаментальный разделитель (не эмодзи-сердечко,
  а тонкая линия/веточка/минималистичный SVG-орнамент)
- Короткая фраза-приглашение над или под именами (на выбранном языке),
  например: «Приглашаем вас разделить с нами этот особенный день»
  (текст должен звучать тепло, не казённо)
- Тонкая подсказка «скролльте вниз» — стрелка или анимированная точка,
  без резких прыжков

### Экран 2 — Детали
- Дата и время крупно и чётко (4 октября, 18:00)
- Место: ресторан «Дидор», Душанбе — с возможностью тапнуть и открыть в Google Maps
  (просто ссылка на поиск "Дидор Душанбе" в Google Maps, координаты не обязательны)
- Кнопка «Добавить в календарь» (генерация .ics-файла на клиенте, без бэкенда)
- Блок контактов — два имени с ролями (отец жениха / отец невесты)
  и кликабельные номера (tel: и wa.me ссылки для WhatsApp)
- Никаких форм, никакого RSVP — только просмотр и способ связаться

## Анимации и переходы
- GSAP timeline на загрузке экрана 1: лепестки + плавное появление текста
  (fade + небольшой translateY, стаггер по буквам/словам для имён — но без вычурности)
- Плавный скролл-переход между экранами (можно snap-scroll на десктопе,
  на мобильных — обычный нативный скролл, не блокировать touch)
- Все анимации — soft easing (power2.out / expo.out), никаких резких bounce

## Производительность (важно!)
- Ссылку откроют гости на слабом мобильном интернете — сайт обязан быть лёгким:
  - Изображения (если есть) — сжатые WebP, лепестки лучше как inline SVG,
    а не PNG-спрайты
  - Шрифты — не больше 2 семейств, с font-display: swap и подгрузкой только
    нужных начертаний/символов (кириллица + при необходимости доп. символы
    для таджикского)
  - GSAP — только нужные плагины, не весь пакет
- Обязательный экран/анимация загрузки (loading state), чтобы «вау-эффект»
  сохранился, даже если шрифт, скрипт или картинка подгружаются с задержкой —
  пользователь не должен видеть «прыгающий» неоформленный контент (FOUC)

## Метаданные для шеринга
- Настроить Open Graph / Twitter Card теги, чтобы при пересылке ссылки
  в WhatsApp/Telegram превью показывало красивую картинку-обложку
  (например, тизер с именами и датой) и короткий текст-приглашение

## Адаптивность
- Приоритет — мобильный экран (это основной способ просмотра)
- Десктопная версия — та же композиция, аккуратно центрированная,
  без растягивания на весь широкий экран

## Дополнительные идеи (по желанию, можно предложить как опции)
- Тихая фоновая музыка с ненавязчивой кнопкой mute/unmute (выключено по умолчанию,
  включается по клику — браузеры всё равно блокируют автоплей со звуком)
- Обратный отсчёт до даты свадьбы мелким текстом на экране 2
- Кнопка «Поделиться» (Web Share API с фолбэком на копирование ссылки)
- Маленький дот-индикатор экрана 1/2 сбоку, в духе Nothing OS

## Что нужно на выходе
Полный рабочий код (Vue 3 SFC-компоненты + Tailwind-конфиг + GSAP-анимации),
с текстовым контентом на русском и таджикском языках, готовый к деплою
как статический сайт.
