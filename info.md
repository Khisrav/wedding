КРИТИЧНО: МЕДЛЕННЫЙ ИНТЕРНЕТ (Таджикистан)
Большинство гостей откроют ссылку на мобильном интернете низкого качества. Вау-эффект не должен зависеть от того, успело ли всё догрузиться.

— Реальный loading screen, а не косметика: показывай его, пока грузятся шрифты/скрипты/критичные ассеты, и убирай только когда всё реально готово (используй document.fonts.ready и Promise.all по ключевым ресурсам), а не по таймеру. Loading-экран уже сам по себе часть NieR-эстетики (boot-строка, мигающий курсор) — он не будет казаться "заглушкой", даже если провисит 3-5 секунд.
— Никаких внешних CDN-запросов в рантайме (шрифты, иконки, GSAP) — всё собирается и отдаётся с одного домена/бандла. Один упавший внешний запрос не должен ломать вид сайта.
— Шрифты: font-display: swap + локальный fallback-стек (system-ui), подобранный так, чтобы даже без кастомного шрифта тайпографика не "разъезжалась" (близкий x-height, похожий трекинг). Если шрифт не догрузился за N мс — сайт всё равно выглядит собранно.
— Картинки (если будут) — WebP/AVIF с фолбэком, ленивая загрузка вне первого экрана, явные width/height чтобы не было CLS. Но по возможности первый экран — вообще без растровых картинок: лепестки как SVG/canvas дешевле любого PNG.
— GSAP и вся анимационная логика — один бандл, code splitting: второй блок (информация) не должен ждать загрузки анимаций первого блока, чтобы контактные номера были доступны, даже если "вау-часть" ещё тормозит.
— Все ассеты сжаты и заинлайнены разумно (маленькие SVG — inline, не отдельным запросом); итоговый бандл — цель <150-200kb gzip на первый экран.
— Если что-то всё же не загрузилось (шрифт/скрипт) — предусмотри лёгкий css-based фолбэк-вид блоков (рамки, текст, цвета — на чистом CSS без JS), чтобы приглашение читалось даже в "деградированном" состоянии, а не выглядело сломанным.
— PWA-манифест и Service Worker — по желанию, но реально полезно: кто откроет ссылку второй раз (например, чтобы посмотреть контакты ещё раз), получит мгновенную загрузку из кэша.

ОТ СЕБЯ ДОБАВЛЮ:
— Переключатель языка должен реально менять весь текст (простой объект с ключами ru/tj, а не два разных блока), по умолчанию должен быть таджикский.
— Звук по умолчанию выключен, но можно добавить тихий эмбиент/UI-щелчки с кнопкой mute/unmute в углу (в духе игры, но ненавязчиво — многие откроют в общественном месте).
— Кастомный курсор на десктопе (крестик/прицел в стиле HUD), на мобильных — обычный.
— Тонкая сетка/circuit-паттерн фоном (SVG, низкая непрозрачность), а не сплошной цвет — добавляет глубины без веса.
— Производительность: лепестки — canvas или лёгкие SVG, не десятки DOM-нод с фильтрами; ScrollTrigger только там, где реально нужен; lazy-init тяжёлых анимаций.
— OG-теги/превью для мессенджеров (заголовок, короткое описание, картинка-превью — можно тот же кадр с лепестками).
— Сделай доступным: достаточный контраст текста на бежевом фоне, prefers-reduced-motion — уменьшать/убирать анимации.
